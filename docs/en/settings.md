# Settings

All settings are located in the **Select Survey** window.

| Setting | Location | Description |
| --- | --- | --- |
| Survey | List on the left | The survey to display. Required. The search filters by title. |
| Survey Installation ID | “Content” tab | Select this manually: enter the full survey URL or the 24-character string at the end of it. Required if the list is missing or the survey is not managed. |
| Survey plugin address | “Advanced” tab | Technical address of the survey app. Set by default and generally to be left **unchanged**. Only adjust if the organization’s survey app is hosted in a different region—this is something the IT department knows, not the editorial team. |

## About the Selection List

The list shows only surveys for which you have **administrative rights**. A
third-party survey that you are permitted to embed will not appear there; however,
you can still add it by entering the address.
