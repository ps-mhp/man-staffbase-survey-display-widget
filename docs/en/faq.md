# FAQ

**Question:** The poll isn't showing up—what could be causing this?

Answer: Most often, the installation ID is missing or incorrect. To
check, enter the survey’s full URL directly into the field—
the widget retrieves the ID itself, so a typo in the
ID itself is impossible.

**Question:** When do I need to change the “Survey Plugin Address”?

Answer: Only if the organization’s survey app is located in a different region
than the default setting. Normally, this field remains unchanged.

**Question:** Can I also use this widget to create new surveys or
edit questions?

Answer: No. The widget only displays a survey that has already been created;
questions, the survey period, and results are still managed exclusively through the
Staffbase Survey app.
