# FAQ

**Question:** The message “No installation ID configured. Please enter the ID of the
survey in the widget settings” appears.

Answer: No survey has been selected. Select a survey from the list or
enter the full survey URL in the field.

**Question:** The message “Survey could not be loaded” appears.

Answer: In most cases, the installation ID is incorrect, or the survey has been
deleted or is not published. To check, enter the full address
of the survey into the field again. If the message also includes a
web address, the survey app was not found at the entered address
— in that case, reset the “Survey Plugin Address” field to its default
setting.

**Question:** The configuration dialog says, “The list of surveys could not be
loaded. Please enter the installation ID.”

Answer: No need to worry—the drop-down list is just a convenience feature.
Just enter the full address of the survey in the field; that’s all you need to do.

**Question:** When do I need to change the “Survey Plugin Address”?

Answer: Practically never. Only if the organization’s survey app is located in a
region other than the default. If in doubt, leave it unchanged and
ask IT.

**Question:** Can I edit questions or analyze results
using this widget?

Answer: No. Questions, the survey period, and analysis are handled exclusively in the
Staffbase Surveys app.

**Question:** Someone has already voted and now sees something different than
I do.

Answer: That’s normal. The widget displays the survey exactly as the
Surveys app displays it for that person—meaning, depending on the status, the form,
a thank-you message, or the results.

**Question:** Do responses count twice if I embed the same survey on multiple
pages?

Answer: No. It’s the same survey everywhere with a shared
analysis.
