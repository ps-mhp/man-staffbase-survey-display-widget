# Step by Step

## Embed a Survey

1. Make sure the survey has been created
   and published in the **Staffbase Surveys app**.
2. Open the landing page for editing and drag the **Survey Display** widget to
   the desired location.
3. Open **Select Survey** on the widget. Select the survey from the list on the left;
   the search bar above filters by title. The list contains the
   surveys that you are authorized to manage.
4. Leave the **survey plugin address** (under the “Advanced” tab)
   unchanged.
5. Select **Apply**, save, and preview the page. The preview in the
   window (desktop, tablet, mobile) is a sample view; the actual poll
   will only appear on the page.

As long as nothing is entered, the message “No
installation ID configured” will appear in that spot—even on the published page.

## If no drop-down list appears

In that case, the “Surveys” column remains empty and indicates the reason. Enter it manually:

1. Open the survey in the Surveys app.
2. Copy the **complete address** from the address bar.
3. Paste it into the **Survey Installation ID** field on the right in the “Content” tab
  — the widget will automatically retrieve the ID.
4. Select **Apply** and save.

## Replace a Survey

1. Open the **Select Survey** window.
2. Select a different survey on the left or paste its address into the **Survey Installation ID**
   field.
3. Select **Apply**, save, and check the page.

## Existing Widgets

Widgets set up before this version will continue to display their
survey as is. The new
setting will take effect only after you make a change in the window and apply it.
