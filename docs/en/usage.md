# Step by Step

## Embed a Survey

1. Make sure the survey has been created
   and published in the **Staffbase Surveys app**.
2. Open the landing page for editing and drag the **Survey Display** widget to
   the desired location.
3. In the **Survey Installation ID** field, select the survey from the drop-down list.
   The list contains the surveys you are authorized to manage.
4. Leave the **Survey Plugin Address** field unchanged.
5. Save and check the preview.

As long as nothing is entered, the message “No
installation ID configured” will appear in that spot—even on the published page.

## If no drop-down list appears

Instead of the list, the message “The list of surveys could not
be loaded” will appear. In this case, enter the information manually:

1. Open the survey in the Survey App.
2. Copy the **full address** from the address bar.
3. Paste it into the **Survey Installation ID** field—the widget will
   automatically retrieve the ID.
4. Save.

## Replace a survey

1. In the **Survey Installation ID** field, select a different survey or
   paste its address.
2. Save and check the preview.
