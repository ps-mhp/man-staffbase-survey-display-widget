# FAQ

**Frage:** Die Umfrage erscheint nicht — woran kann das liegen?

Antwort: Am häufigsten fehlt oder stimmt die Installations-ID nicht. Zur
Kontrolle die vollständige URL der Umfrage direkt in das Feld einfügen —
das Widget liest sich die ID selbst heraus, sodass ein Tippfehler in der
reinen ID ausgeschlossen ist.

**Frage:** Wann muss ich die „Adresse des Umfragen-Plugins“ ändern?

Antwort: Nur wenn die Umfragen-App der Organisation in einer anderen Region
liegt als die Voreinstellung. Im Normalfall bleibt dieses Feld unangetastet.

**Frage:** Kann ich mit diesem Widget auch neue Umfragen erstellen oder
Fragen bearbeiten?

Antwort: Nein. Das Widget zeigt nur eine bereits angelegte Umfrage an;
Fragen, Zeitraum und Auswertung werden weiterhin ausschließlich über die
Staffbase-Umfragen-App verwaltet.
