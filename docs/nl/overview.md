# Enquêteweergave

De enquêteweergave integreert een bestaande Staffbase-enquête-installatie
op de plek waar de widget op een pagina wordt geplaatst. De
enquête zelf wordt nog steeds beheerd via de Staffbase-enquête-app
(vragen, periode, analyse) — deze widget toont alleen de reeds
aangemaakte enquête op een extra plek, bijvoorbeeld op een
startpagina of teampagina in plaats van alleen in het enquêtegedeelte.

Om ervoor te zorgen dat de enquête correct in de pagina wordt geïntegreerd, neemt de widget
automatisch contextinformatie zoals taal en tekstrichting over van de
omringende pagina — hiervoor is geen extra instelling nodig.
