# Veelgestelde vragen

**Vraag:** De enquête verschijnt niet — waaraan kan dat liggen?

Antwoord: Meestal ontbreekt de installatie-ID of is deze onjuist. Voer ter
controle de volledige URL van de enquête rechtstreeks in het veld in —
de widget haalt de ID zelf op, zodat een typefout in de
ID zelf uitgesloten is.

**Vraag:** Wanneer moet ik het „adres van de enquête-plugin“ wijzigen?

Antwoord: Alleen als de enquête-app van de organisatie zich in een andere regio
bevindt dan de standaardinstelling. Normaal gesproken blijft dit veld ongewijzigd.

**Vraag:** Kan ik met deze widget ook nieuwe enquêtes aanmaken of
vragen bewerken?

Antwoord: Nee. De widget toont alleen een reeds aangemaakte enquête;
vragen, periode en evaluatie worden nog steeds uitsluitend via de
Staffbase-enquête-app beheerd.
