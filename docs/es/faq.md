# Preguntas frecuentes

**Pregunta:** La encuesta no aparece, ¿a qué se debe?

Respuesta: Lo más habitual es que falte el ID de instalación o que este sea incorrecto. Para
comprobarlo, introduce la URL completa de la encuesta directamente en el campo:
el widget lee el ID por sí mismo, por lo que se descarta que haya un error tipográfico en el
propio ID.

**Pregunta:** ¿Cuándo debo cambiar la «dirección del complemento de encuestas»?

Respuesta: Solo si la aplicación de encuestas de la organización se encuentra en una región
diferente a la predeterminada. Normalmente, este campo no debe modificarse.

**Pregunta:** ¿Puedo utilizar este widget para crear nuevas encuestas o
editar preguntas?

Respuesta: No. El widget solo muestra una encuesta ya creada;
las preguntas, el periodo y la evaluación siguen gestionándose exclusivamente a través de la
aplicación de encuestas de Staffbase.
