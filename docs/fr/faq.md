# FAQ

**Question :** Le sondage ne s'affiche pas — à quoi cela peut-il être dû ?

Réponse : Le plus souvent, l'identifiant d'installation est manquant ou incorrect. Pour
vérifier, collez l'URL complète du sondage directement dans le champ —
le widget récupère lui-même l'identifiant, ce qui exclut toute erreur de frappe dans l'
identifiant lui-même.

**Question :** Quand dois-je modifier l’« adresse du plugin de sondage » ?

Réponse : Uniquement si l’application de sondage de l’organisation se trouve dans une région
différente de celle par défaut. En règle générale, ce champ ne doit pas être modifié.

**Question :** Puis-je également créer de nouveaux sondages ou
modifier des questions à l'aide de ce widget ?

Réponse : Non. Le widget affiche uniquement un sondage déjà créé ;
les questions, la période et l'analyse continuent d'être gérées exclusivement via l'
application de sondages Staffbase.
