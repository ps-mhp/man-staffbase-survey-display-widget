# FAQ

**Question :** Le message « Aucun identifiant d'installation n'est configuré. Veuillez saisir l'identifiant du
sondage dans les paramètres du widget. » s'affiche.

Réponse : Aucun sondage n'est sélectionné. Sélectionnez un sondage dans la liste ou
saisissez l'adresse complète du sondage dans le champ.

**Question :** Le message « Impossible de charger le sondage » s'affiche.

Réponse : La plupart du temps, l'ID d'installation est incorrect, ou le sondage a été
supprimé ou n'est pas publié. Pour vérifier,
saisissez à nouveau l’adresse complète
du sondage dans le champ. Si le message contient également une
adresse Web, cela signifie que l’application de sondage n’a pas été
trouvée à l’adresse saisie — dans ce cas, réinitialisez le champ « Adresse du plugin de sondage »
à sa valeur par défaut.

**Question :** Dans la boîte de dialogue de configuration, le message suivant s’affiche : « La liste des sondages n’a pas pu
être chargée. Veuillez saisir l’identifiant d’installation. »

Réponse : Pas d’inquiétude — la liste de sélection n’est qu’une aide à la saisie.
Il suffit d’insérer l’adresse complète du sondage dans le champ prévu à cet effet.

**Question :** Quand dois-je modifier l’« adresse du plugin de sondage » ?

Réponse : Pratiquement jamais. Uniquement si l’application de sondage de l’organisation se trouve dans une
autre région que celle par défaut. En cas de doute, ne rien modifier et
demander conseil au service informatique.

**Question :** Puis-je modifier des questions ou analyser les résultats
à l’aide de ce widget ?

Réponse : Non. Les questions, la période et l’analyse se trouvent exclusivement dans l’
application de sondages Staffbase.

**Question :** Une personne a déjà voté et voit désormais quelque chose de différent de ce que
je vois.

Réponse : C'est normal. Le widget affiche le sondage exactement tel que l'
application de sondage le présente à cette personne — c'est-à-dire, selon l'état d'avancement, le formulaire,
un message de remerciement ou les résultats.

**Question :** Les réponses sont-elles comptées deux fois si j’intègre le même sondage sur plusieurs
pages ?

Réponse : Non. Il s’agit partout du même sondage avec une
évaluation commune.
