# Affichage du sondage

L'affichage du sondage intègre une installation de sondage Staffbase existante
à l'endroit où le widget est placé sur une page. Le
sondage lui-même continue d’être géré via l’application Sondages de Staffbase
(questions, période, analyse) — ce widget affiche simplement le
sondage déjà créé à un emplacement supplémentaire, par exemple sur une
page d’accueil ou une page d’équipe, et non plus uniquement dans la section Sondages.

Pour que le sondage s’intègre correctement à la page, le widget
reprend automatiquement les informations contextuelles telles que la langue et le sens d’écriture de la
page environnante — aucun paramétrage supplémentaire n’est nécessaire.
