# Paramètres

| Paramètre | Description |
| --- | --- |
| ID d'installation du sondage | Le sondage à afficher. Champ obligatoire. À sélectionner normalement dans la liste déroulante ; vous pouvez également saisir l'adresse complète du sondage ou la chaîne de 24 caractères figurant à la fin de celle-ci. |
| Adresse du plugin de sondage | Adresse technique de l’application de sondage. Valeur par défaut ; à laisser **inchangée** en règle générale. À modifier uniquement si l’application de sondage de l’organisation est hébergée dans une autre région — c’est le service informatique qui en a connaissance, pas la rédaction. |

## À propos de la liste de sélection

La liste n'affiche que les sondages pour lesquels vous disposez de **droits d'administration**. Un
sondage tiers que vous êtes autorisé à intégrer n'y apparaîtra donc pas ; il
peut néanmoins être ajouté en insérant son adresse.
