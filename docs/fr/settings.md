# Paramètres

| Paramètre | Description |
| --- | --- |
| ID d'installation du sondage | L'ID de l'installation du sondage à afficher — la chaîne de 24 caractères située à la fin de l'URL du sondage. Champ obligatoire. |
| Adresse du plugin de sondage | À modifier uniquement si l'application de sondage se trouve dans une région différente de celle par défaut. À laisser inchangée en règle générale. |

Au lieu de l'identifiant seul, il est également possible d'insérer l'
URL complète du sondage dans le champ « Identifiant d'installation du sondage » ; le widget en extraira
lui-même l'identifiant.
