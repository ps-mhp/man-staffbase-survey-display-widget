# Paramètres

Tous les paramètres se trouvent dans la fenêtre **Sélectionner un sondage**.

| Paramètre | Emplacement | Description |
| --- | --- | --- |
| Sondage | Liste à gauche | Le sondage à afficher. Obligatoire. La recherche s'effectue par titre. |
| ID d'installation du sondage | Onglet « Contenu » | Sélection manuelle : saisissez l'adresse complète du sondage ou la chaîne de 24 caractères figurant à la fin de celle-ci. Nécessaire si la liste est manquante ou si le sondage n'est pas géré. |
| Adresse du plugin de sondage | Onglet « Avancé » | Adresse technique de l’application de sondage. Valeur par défaut à laisser **inchangée** en règle générale. À modifier uniquement si l’application de sondages de l’organisation est hébergée dans une autre région — c’est le service informatique qui en a connaissance, pas la rédaction. |

## À propos de la liste de sélection

La liste n'affiche que les sondages pour lesquels vous disposez de **droits d'administration**. Un
sondage tiers que vous êtes autorisé à intégrer n'y apparaîtra donc pas ; il
peut néanmoins être ajouté en saisissant son adresse.
