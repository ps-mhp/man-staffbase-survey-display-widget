# Definições

| Definição | Descrição |
| --- | --- |
| ID de instalação do inquérito | O ID da instalação do inquérito a apresentar — a sequência de 24 caracteres no final do URL do inquérito. Campo obrigatório. |
| Endereço do plugin da sondagem | Altere apenas se a aplicação da sondagem estiver localizada numa região diferente da predefinida. Normalmente, deve deixar este campo inalterado. |

Em vez do ID puro, também é possível inserir a
URL completa da sondagem no campo «ID de instalação da sondagem»; o widget extrai o ID
automaticamente a partir dessa URL.
