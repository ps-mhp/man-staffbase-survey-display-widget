# Perguntas Frequentes

**Pergunta:** O inquérito não aparece — qual poderá ser a razão?

Resposta: Na maioria das vezes, falta o ID de instalação ou este está incorreto. Para
verificar, insira o URL completo do inquérito diretamente no campo —
o widget lê o ID automaticamente, pelo que é impossível que haja um erro de digitação no
próprio ID.

**Pergunta:** Quando devo alterar o «Endereço do plugin de inquéritos»?

Resposta: Apenas se a aplicação de inquéritos da organização estiver numa região
diferente da predefinida. Normalmente, este campo não deve ser alterado.

**Pergunta:** Posso também criar novas sondagens ou
editar perguntas com este widget?

Resposta: Não. O widget apenas apresenta uma sondagem já criada;
as perguntas, o período e a avaliação continuam a ser geridos exclusivamente através da
aplicação de sondagens da Staffbase.
