# Umfrage-Anzeige

Die Umfrage-Anzeige bettet eine bestehende Staffbase-Umfrage-Installation an
der Stelle ein, an der das Widget auf einer Seite platziert wird. Die
Umfrage selbst wird weiterhin über die Staffbase-Umfragen-App verwaltet
(Fragen, Zeitraum, Auswertung) — dieses Widget zeigt nur die schon
angelegte Umfrage an einer zusätzlichen Stelle an, etwa auf einer
Startseite oder Team-Seite statt nur im Umfragen-Bereich.

Damit die Umfrage sich korrekt in die Seite einfügt, übernimmt das Widget
automatisch Kontextinformationen wie Sprache und Textrichtung von der
umgebenden Seite — dafür ist keine zusätzliche Einstellung nötig.
